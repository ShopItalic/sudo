What changed

A zero PWM flag allowed a cue to finish without delivering the STOPPED event. The motor owner could remain active indefinitely, so battery acquisition correctly refused to measure and returned ADC 65535 / percentage 255. Finite cues now request PWM_FLAG_STOP; loops use PWM_FLAG_LOOP.

The repair retains battery arithmetic, calibration, sampling cadence, active-motor exclusion, post-motor settling, charger checks and stack allocations. The reviewed battery task uses 496 of 1,024 bytes: 528 spare, or 272 after the existing 256-byte provisional reserve. Linker reports do not establish complete runtime bounds.

  • P08: compact battery reporting, corrected averaging, local recording and saved-file transfer.
  • P09: the same fix plus the controls recording-busy guard; retains short-recording filtering and optional scrolling.
  • P10: persistent receiver receipts and bounded automatic cleanup, plus the P09 and battery fixes. The app refuses downgrade from P10 to older settings formats.

Distribution decision

The temporary private-repository setting caused HTTP 404 responses to the app's anonymous catalog and package requests. Jeremy restored the existing repository to public visibility, and both download routes were reverified. No separate repository, hosting service or app authentication change was needed. Historical private-download failures remain in the local diagnostics as evidence of the resolved issue.

For future reference, source access and firmware delivery can be separated. Public firmware delivery is established: LVFS distributes firmware through a public service, and its metadata supports proprietary firmware. Restricted delivery is also established: AWS IoT supports time-limited download URLs. A downloads-only repository remains an option if the source should become private later. A signature establishes authenticity; it does not hide compiled firmware or replace physical qualification. Signing keys are never distribution assets.
