Factory P05

Sample-test prerelease · physical qualification pending

A small factory-firmware change for hold-to-record, programmable taps and a Ring-owned haptics setting.

Behavior

Press and holdPTT starts after 500 ms. Release stops recording. A 750 ms sensor-report lease stops an uncertain hold.
Double / triple tapRecording is off by default. Each can be set to Off or Start/stop recording in the matching app. Triple tap retains the factory key event when its recording action is off.
HapticsOn by default. The app switch writes a persistent setting to the Ring and mutes normal application motor paths.
SettingsThe app reads Ring state first. Saves require an idle recorder, released touch and matching revision. Acknowledgement follows durable storage, then independent readback.
App recording stateFactory completion events and a nonce-correlated state query update recording status and schedule the existing ADPCM transfer flow.

Scope and source

The preparation script extracts factory commit 102bfd263952caaf532f0d53041b1f35bdfa943a, verifies all 7,056 files, changes nine originals and adds five source files. No new tasks are created. Recorder, audio format, filesystem, sensor configuration, bootloader, SoftDevice and provisioning remain the factory versions.

Prepare the source with python3 tools/firmware/prepare_factory_ptt_v5.py --output build/p05-source, then compile the generated P05 build-only project with the authorized Arm Compiler 5.06u7 build 960 environment. The shared P03 preparation module is a helper; previous generated RC trees are not inputs. The separate GNU CI output is an engineering check of the main candidate, not this P05 application.

Cloud download and sample testing

Use the app's cloud firmware selector backed by the curated GitHub catalog. The package is BCL603S2P_6.0.3.3P05.zip on the P05 prerelease. Downloading stages the package; installation is a separate action.

This application was locally packaged with the supplier DFU signing key. Signature compatibility does not mean supplier approval or physical qualification. Software checks cannot guarantee that a sealed Ring will remain usable after installation; recovery has not been demonstrated.

  1. Verify the intended Ring reports hardware 603V1.23.2 and factory firmware 6.0.3.3Z62. Confirm existing recordings have transferred.
  2. Charge to at least the app's 50% minimum, then remove the Ring from the charger. Keep the phone and Ring close, connected and idle.
  3. After an explicitly chosen sample installation, first verify reconnection and firmware 6.0.3.3P05, then check settings readback.
  4. Test a short stationary hold/release, then a longer hold; verify the complete recording transfers and plays through its tail.
  5. Test each tap mapping separately, haptics off/on and settings persistence across restart, then reconnect and interruption behavior.
Source, build and package checks are separate from physical boot, touch, PWM/FDS, battery and audio-custody verification.
