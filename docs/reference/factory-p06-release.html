Factory P06: recording controls

Application-only sample-test release, built from the verified factory Z62 source using licensed Arm Compiler 5. This is an incremental extension of P05.

What changes

ControlBehavior
Hold to start0.5–5 seconds in half-second steps; default 0.5 seconds. Early release cancels; release after activation stops recording.
Recording lightIndependent saved on/off preference, default on. Haptics remain independent.
Stored settingsExisting P04/P05 settings are preserved. Older app writes preserve settings absent from their requests. Changes become active after the durable write succeeds.

The factory recorder, filesystem, codec, sensor configuration, bootloader, SoftDevice and provisioning layout remain unchanged from the P05 preparation. Swipe events are retained; this release does not add app swipe-action mappings or transfer-speed changes.

Compatibility and installation

P06 writes settings schema 3, which P05 cannot read. Use the matching app with fresh-version downgrade checks. Do not present P05 or Z62 as a supported rollback from P06. The unpublished longer-delay prototype is read without a boot-time write; only a delay above five seconds is normalized to five seconds.

The package is signed locally using the supplier DFU key and independently verified against the public key embedded in the preserved factory bootloader. This is not supplier acceptance. Only the application is updated. A matching board identity, sufficient fresh battery, off-charger state, idle recording and exclusive update access are checked before transfer.

Evidence and qualification

Release assets contain the exact package hash, compiler result, source reproduction and load/stack verification. Firmware host regressions and iOS checks are separate from physical evidence. Static stack checks do not establish runtime high-water use.

Installation is authorized for Jeremy’s existing D814 sample with the known recovery limitation. Verify fresh P06 readback, saved controls and subsequent audio transfer. No general physical qualification or recovery guarantee is claimed. If the update outcome is uncertain, use Check installation; do not automatically reflash.
