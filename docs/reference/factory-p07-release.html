Ring 6.0.3.3P07

Sample-test release · 603V1.23.2 · September 15, 2026

Controls

Four independent Up, Down, Left and Right swipe switches, all on by default. Enabled swipes emit the existing factory key events; no new recording or navigation action is assigned. The iPhone app reads and saves each switch on the connected Ring.

Includes hold/release push to talk, a 0.5–5 second hold setting in 0.5-second increments (default 0.5), programmable double/triple tap recording (off by default), haptics and recording-light switches (on by default). Settings from P04–P06 migrate in memory without a boot-time write. The app refuses firmware downgrades that cannot read saved settings.

Build and package evidence

Fresh preserved factory Z62 source with the P07 overlay. Licensed Arm Compiler 5.06 update 7 build 960: zero errors, 543 inherited warnings. Factory bootloader, SoftDevice and sensor configuration preserved. Application-only package signed locally using the supplier DFU key; this does not represent supplier approval.

Application: 187,096 bytes. SHA-256 2a24d2a13e818f78c508649722387c875f4d64cd9df5673810044dd1fb584648.

Signed OTA ZIP: 187,672 bytes. SHA-256 2277d8d75a71906a175f615affb2404b339c5a14a422bf144ac5761e14e5166e.

Independent ECDSA signature, vectors, flash/RAM bounds and source isolation checks passed. Host controls and timing tests passed, including all four missing-swipe-gate negative controls. Application counter 1; hardware 52; SoftDevice requirement 0x0100.

Qualification boundary

This is a sample-test prerelease. P07 boot, real swipe recognition, persistence, audio transfer and update completion without restarting the iPhone app are not yet physically qualified. Static checks cannot guarantee a sealed Ring is recoverable or cannot be bricked. No recovery method is demonstrated. P05 was previously installed on the intended sample.

Download only the signed ZIP through the matching iPhone app. The app must confirm the target identity, fresh battery/charging state and exact package digest before installation. Allow at least five minutes and keep the app open; the earlier P05 test took about eleven minutes including a reconnect problem. Do not start a second flash while installation is uncertain.
